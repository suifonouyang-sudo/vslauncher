## 虚拟屏桌面 v1.2

### 更新内容
- **应用列表只显示可启动的应用**：自动隐藏没有桌面入口（无图标）的系统组件 / 服务类软件，列表更干净
- **新增「刷新」按钮**：应用页可一键重新扫描已安装应用并刷新列表
- **虚拟屏移到首页**：底部 Tab 顺序调整为「虚拟屏 → 应用 → 日志」，打开应用默认就在虚拟屏页

### 使用说明
本应用**不创建虚拟屏**，需先用外部命令建好：
```bash
adb shell settings put global overlay_display_devices "720x1280/280"
```
建好后回到「虚拟屏」页点「刷新」即可在列表看到。点应用会先让你选择目标屏幕（物理屏 / 系统虚拟屏 / 第三方屏），选完才启动。

### 实机验证（Android 11）
- 无入口软件已过滤：原 185 个 → 现在显示 44 个（隐藏 144 个）
- 刷新按钮可用：日志出现「应用列表刷新：用户 39 · 系统 5」
- 默认进入虚拟屏页，Tab 顺序正确
- `logcat -b crash` 无输出
